# Aura · 音乐

高自由度、高级美感的桌面音乐播放器。封面主色驱动氛围光，五种视图、四种正在播放布局、四类频谱可视化全部可调，数据源可在「内置演示数据」与「QQ 音乐」之间一键切换。

```
npm install
npm start        # 启动桌面应用
npm run dev      # 带开发者工具
npm run serve    # 纯浏览器调试（localhost:4173，已禁用缓存）
```

也可以直接用浏览器打开 `app/index.html`（无需构建），此时仅缺少窗口控制、媒体键与跨域代理等桌面能力，播放与界面完全可用。

> 改完代码看不到变化时，用 `npm run serve` 而不是 `python3 -m http.server`：后者不发送 `Cache-Control`，浏览器会启发式缓存旧文件。

## 它长什么样

- **氛围光背景**：从当前曲目封面提取主色，驱动三团缓慢漂移的辉光 + 胶片颗粒，整机色调随歌而变。
- **顶部胶囊导航**：全站唯一的顶部栏——悬浮于内容之上的玻璃胶囊，全圆角、极细描边、上缘高光。品牌、后退/前进、四个主导航、数据源、队列、设置全部收在这一条里；内容从它下方滚过，窄窗口自动收纳文字只留图标。它同时是自绘标题栏的拖动把手。
- **玻璃拟态**：顶部胶囊导航、播放条、卡片、弹层统一使用可调强度的毛玻璃。
- **正在播放**：沉浸 / 分栏 / 列表 / 画布四种排布，同一份骨架只换 `data-layout`。
- **频谱可视化**：柱状 / 波形 / 环形 / 粒子四种风格，灵敏度可调；无音频数据时自动降级为合成动画。

## 高自由度体现在哪

| 维度 | 可调项 |
| --- | --- |
| 主题与配色 | 明暗主题、强调色（封面自动提取 / 8 种预设手选）、玻璃开关与模糊强度、环境光开关与强度、颗粒感 |
| 布局 | 顶部胶囊导航（窄窗口自动收成图标）、行密度（紧凑 / 舒适 / 宽松）、圆角缩放、字号缩放、正在播放四种布局 |
| 播放内核 | 倍速、增益、淡入淡出、交叉淡化、空间感（混响）、立体声宽度、6 组 EQ 预设 + 5 段手动均衡 |
| 歌词与可视化 | 翻译轨道开关、歌词字号、可视化开关 / 风格 / 灵敏度 |
| 数据源 | 内置演示数据 ⇄ QQ 音乐，服务地址、登录 Cookie、音质（128 / 320 / flac）可填 |

所有偏好即时生效并持久化到 `localStorage`。

## 架构要点

**数据源用适配器隔离。** 视图只调用 `Aura.api.*`，完全不关心背后是演示数据还是 QQ 音乐。`mock-adapter.js` 与 `qq-adapter.js` 实现同一套接口，切换数据源就是换一个实例，UI 零改动。新增数据源 = 再写一个适配器。

**交互集中在动作注册表。** 视图只拼 HTML 字符串并声明 `data-act` / `data-input` / `data-change`，`ui.js` 安装一次性事件委托统一分发到 `Aura.actions`。因此不存在「渲染完忘记绑事件」，也不会随重绘泄漏监听器。

**状态单向流动。** `store.set()` 返回本次变更的顶层键名，`app.js` 的 `syncShell` 据此做定点更新：换歌才重绘，进度只改歌词激活态，避免每 250ms 的进度回写打断歌词滚动与频谱。

**为什么用 `aura://` 自定义协议。** `file://` 页面是不透明源，把本地封面画进 canvas 后 `getImageData` 会抛跨域错误，「封面主色驱动氛围光」这一核心特性会失效。改用标准协议后渲染层拥有真实同源，问题一并解决。

**没有音频文件也能播。** 演示数据不含音频，`audio.js` 的 `SynthBackend` 会以曲目 id 为种子程序化合成一段环境音，播放 / 进度 / 跳转 / 频谱全部真实可用。接入 QQ 音乐后自动切换到 `ElementBackend` 播放真实音源。

## 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` `→` | 后退 / 前进 5 秒（按住 `Shift` 为 30 秒） |
| `↑` `↓` | 音量 ±5% |
| `/` 或 `⌘F` | 跳到搜索并聚焦输入框 |
| `⌘1` ~ `⌘4` | 首页 / 资料库 / 搜索 / 正在播放 |
| `Esc` | 关闭弹层、菜单，或让输入框失焦 |

macOS 下还会注册系统媒体键（播放 / 暂停、上一首、下一首）。

## 接入真实数据源

默认使用内置演示数据，开箱即用、完全离线。要播放真实音源，需要在本机跑一个第三方 QQ 音乐 API 服务，然后在「设置 → 数据源」里填写服务地址与登录 Cookie。

完整步骤、接口约定与排错见 [docs/qq-music.md](docs/qq-music.md)；若你想自建后端，见 [docs/backend-contract.md](docs/backend-contract.md)。

> 本项目不含任何第三方版权内容。演示数据中的艺人、专辑、曲目与歌词均为虚构或原创。请自行确保所接入的数据源与音源符合当地法律及服务条款。
